# Esportazione dell’UDA

La pagina prepara un archivio ZIP protetto da una password obbligatoria, con i contenuti selezionati dell’UDA. Le sezioni si possono includere o escludere.

![Sezioni e opzioni di esportazione dell’UDA UML](assets/esportazione.jpg)

*Selezione delle sezioni e opzioni per generare il pacchetto dell’UDA.*

## Sezioni e opzioni

| Controllo | Effetto |
| --- | --- |
| Informazioni generali | Include i metadati e la descrizione dell’UDA. |
| Obiettivi | Include gli obiettivi associati all’unità. |
| Materiali | Include l’elenco e i riferimenti alle risorse. |
| Rubriche | Include gli indicatori e le rubriche didattiche previste. |
| Laboratorio | Include i dati della griglia e delle valutazioni pertinenti. |
| Domande | Include l’archivio delle domande associato. |
| Test | Include le prove e le attività collegate. |
| Statistiche | Include i riepiloghi disponibili nell’esportazione. |
| Seleziona tutto / Deseleziona tutto | Attiva o rimuove in blocco la selezione delle sezioni. |
| Password | È obbligatoria e deve contenere almeno quattro caratteri; serve ad aprire il pacchetto ZIP protetto, quindi conservala. |
| Genera Pacchetto ZIP protetto | Prepara il pacchetto protetto. Al termine compare il pulsante separato **Scarica Pacchetto ZIP**, che avvia il download. |

## Esempio di esportazione

1. Apri l’esportazione dalla scheda UML e controlla il titolo dell’unità.
2. Seleziona le sezioni necessarie oppure usa **Seleziona tutto**.
3. Inserisci e conserva una password di almeno quattro caratteri: è obbligatoria per creare e riaprire il pacchetto.
4. Controlla le sezioni selezionate e le opzioni, poi premi **Genera Pacchetto ZIP protetto**.
5. Quando la preparazione è terminata, premi **Scarica Pacchetto ZIP** per salvare il file.

> L’archivio non è stato generato durante la ricognizione. La pagina consente di includere le sezioni attualmente disponibili e produce un file locale da conservare.

## Contenuto effettivo del pacchetto

La pagina di esportazione indica che il pacchetto può contenere:

- documento Word con le informazioni e le sezioni didattiche selezionate;
- file Excel con voti, valutazioni e risposte ai test;
- materiali, obiettivi, rubriche, laboratorio, domande, test e statistiche secondo le caselle spuntate.

Nella consultazione dell’UDA UML risultavano 0 obiettivi, 2 materiali, 6 rubriche, 0 elementi di laboratorio, 16 domande e 1 classe nel riepilogo dell’esportazione. Questi valori sono un’istantanea della UDA e possono cambiare dopo nuove associazioni.

## Protezione e trattamento dei dati

Il pacchetto può contenere nominativi, voti, giudizi, risposte e riferimenti a servizi esterni. Usa una password diversa dalle credenziali dell’applicazione, consegnala tramite un canale separato e non caricare lo ZIP in repository pubbliche o issue. Anche un archivio protetto non deve essere trattato come materiale da pubblicare: il nome del file, la password e i link inclusi possono comunque rivelare informazioni.
